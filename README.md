Arun Yadav - Personal Portfolio
A personal portfolio website built with HTML, CSS and vanilla JavaScript. The project is based on a supplied portfolio design and has been personalized with my name and student/developer introduction.
About the project
The website presents my introduction, selected projects, recommendations, contact information and footer links. It is a frontend-only project created as part of a frontend development assignment.
Technologies used
- HTML5 - page structure and content
- CSS3 - layout, colors, typography and responsive styling
- JavaScript - interactive navigation, recommendations carousel and contact-form demo behaviour

How to run locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html.
4. Right-click in the editor and select Open with Live Server. You can also open index.html directly in a browser.
5. No package installation, build tool, backend or database is required.
JavaScript features
- Mobile navigation menu
- Recommendations carousel with active slide indicators
- Frontend-only contact form feedback
The contact form is a demonstration. It does not send messages to a server or store submitted information.
Customization
- Update text and section content in index.html.
- Change colors, spacing and responsive styles in style.css.
- Update interactions in script.js.
- Replace images and icons inside assets/ while keeping the file paths in the HTML correct.
Before publishing, replace sample project descriptions, recommendation text, contact details and social links with accurate information. Only include genuine recommendations and working profile links.
